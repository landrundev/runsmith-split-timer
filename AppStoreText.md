## Description

Runsmith Split Timer is the precision timing tool built for track & field coaches, parents, and fans. Whether you're coaching a full roster or cheering on your kid at their first 800m, Runsmith has you covered.

TWO MODES, ONE APP

Fan Mode — Made for parents and fans. Add your athlete, pick an event, and start timing in seconds. See their PR history, performance trends, and post-race insights without any coaching setup.

Coach Mode — Full team management. Build rosters, organize meets, coordinate multi-coach timing, run relay races, and analyze your entire season from a single dashboard.

LIVE SPLIT TIMING
- Tap-to-mark splits with a real-time elapsed clock
- Assign marks to athletes on the fly or tap athlete cards directly
- Per-lap timer resets on every split so you can see current pace live
- Adaptive layout: full cards for small groups, compact grid for large fields
- Undo any split or mark — nothing is permanent until the race is over
- Crash recovery saves mid-race state continuously

EVERY EVENT
- Individual events from 100m to 10,000m
- 110m Hurdles and 300m Hurdles
- 4x100m, 4x200m, 4x400m, and 4x800m relays with leg breakdowns
- Custom distance events and unlimited splits mode
- Adjustable splits per lap (1–4) for detailed intermediate tracking
- Fractional lap display for sub-track distances (100m = 1/4 Lap, etc.)

RELAY BUILDER
- Build relay teams ranked by PR or season average
- Save teams, reorder legs, and record optional intermediate splits
- Gender-filtered team suggestions from your roster

PRE-RACE ANALYTICS
- Personal best, race count, last result, best lap, and trend for the event
- Performance trend analysis across the last 5 races
- PR differential showing how close the last race was
- Multi-athlete view with inline stats for every runner
- Relay team history with best time and race count

POST-RACE INSIGHTS
- Instant PR detection after every finish
- Personal best comparisons and best lap analysis
- Relay team records and fastest leg highlights
- "First race!" celebrations for new events

RESULTS & SHARING
- Cumulative and lap time views with split breakdowns
- Share results as image cards or export to CSV
- Add official times with proportional split adjustment
- Meet name, heat, and placement metadata on every race

MULTI-COACH TIMING
- Share race configs via QR code or .runsmith file
- Assistant coaches time independently on their own devices
- Merge splits back with automatic race verification
- Bulk merge all races in a meet at once

MEETS & ORGANIZATION
- Group races by meet with date and location
- Drag-to-reorder races within meets
- Import races between meets
- Full archive system with restore and permanent delete
- WA Official badge for sanctioned meets

ANALYTICS DASHBOARD
- Season overview with race counts and PR trends
- Personal records board across all events
- Event leaderboards with athlete deduplication
- Split-level PRs from intermediate timing data
- Athlete insights with consistency analysis

ATHLETE PROFILES
- Per-athlete race history with meet context
- Personal bests by event with split PRs
- Gold, silver, bronze place indicators
- Relay team context and leg history

100% offline. No account required. No ads. No subscriptions.

Part of the Runsmith platform — the all-in-one coaching suite for track & field. Visit runsmith.com to learn more.

## What's New — v2.3.0

NEW: HURDLE EVENTS
- 110m Hurdles and 300m Hurdles now available in all event pickers
- Hurdle events hide lap/track references for a cleaner display

NEW: LIVE PER-LAP TIMER
- Single-athlete races now show a live lap timer that resets on every split
- See current lap elapsed time in real time, just like relay per-leg timing

NEW: OFFICIAL TIME ENTRY
- Add official times to any completed race
- Proportional split adjustment scales all splits to match the official finish
- Official badge and time displayed in results and athlete profiles

NEW: FRACTIONAL LAP DISPLAY
- Sub-track distances now show fractional laps (100m = 1/4 Lap, 200m = 1/2 Lap)
- Smart fraction simplification using GCD for clean display

IMPROVEMENTS
- Edit Race Info directly from the pre-race staging screen (pencil icon)
- Pre-race detail fields: meet name, heat number, overall and heat placement
- Confirmation dialogs now appear as bottom sheets instead of floating popovers
- Swipe-to-delete athletes in Fan Mode with confirmation
- Share cards include meet name, heat, and placement metadata
- Spectator staging passes all race metadata through to live timing
- Various UI polish and stability improvements
